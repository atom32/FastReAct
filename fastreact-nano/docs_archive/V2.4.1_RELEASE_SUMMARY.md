## Installation & Deployment

### Quick Start

**Backend**:
```bash
cd fastreact-nano
pip install -e ".[all]"
export FASTRACT_API_KEY=sk-xxx
python3 -m fastreact.adapters.gateway
# http://0.0.0.0:9000
```

**Frontend**:
```bash
cd fastreact-nano-web
npm install
npm run dev
# http://localhost:3000
```

### Production

**Backend**:
```bash
pip install "fastreact-nano[all]"
python3 -m fastreact.adapters.gateway --host 0.0.0.0 --port 9000
```

**Frontend**:
```bash
cd fastreact-nano-web
npm run build
npm start
# http://localhost:3000
```
