## Archive Areas

- `analysis/`: durable historical decisions and principles.
- `analysis_raw/`: raw research and exploratory design notes.
- `async/`: async learning/reference notes.
- `bug_fixes/`: historical fixes and lessons learned.
- `deployment/`: older deployment reports and guides.
- `development/`: implementation summaries and development plans.
- `implementation/`: historical implementation reports.
- `reports/`: project status, testing, research, and verification reports.
- `sprints/`: phase/sprint completion records.
- `testing/`: older test reports and E2E summaries.
- top-level files: adapter, multitenant, MCP, gateway, intervention, Feishu, release, and audit notes.

## How To Use This Archive

- Use these files for rationale, timeline, and prior investigations.
- Verify commands, endpoints, config, and security claims against current docs and code before using them.
- Do not link individual archive files from primary user paths unless the doc is explicitly marked historical.
