# Repository Archive Index

Last updated: 2026-06-23

This directory contains historical FastReAct documents from pre-nano, v1, migration, sprint, bugfix, and temporary work. These files are preserved for context and rationale, not as current implementation truth.

Current maintained docs live in:

- [../README.md](../README.md)
- [../fastreact-nano/README.md](../fastreact-nano/README.md)
- [../fastreact-nano/docs/DOCS_INDEX.md](../fastreact-nano/docs/DOCS_INDEX.md)

## Archive Areas

- `old_docs_2026-02_07/`: early root docs, older architecture, feature, tool, research, and status notes.
- `v1_docs/`: v1-era setup, Docker, REPL, IEL, MCP, and configuration material.
- `nano_docs/`: early FastReAct Nano docs before the current `fastreact-nano/` docs center.
- `bugfixes/`: historical bug fix notes.
- `sprints/`: sprint summaries, release notes, and project status snapshots.
- `temp/`: temporary reports, generated analysis, and one-off development artifacts.
- top-level archive files: migration notes, IEL reports, memory/compaction analysis, test summaries, and old service notes.

## How To Use This Archive

- Use archive docs to understand why a decision happened.
- Do not copy commands or API claims from archive docs into current work without checking current code.
- Prefer [../fastreact-nano/docs/HEADLESS_SERVICE.md](../fastreact-nano/docs/HEADLESS_SERVICE.md) for endpoint truth.
- Prefer [../fastreact-nano/docs/CONFIG_FILE_LOCATIONS.md](../fastreact-nano/docs/CONFIG_FILE_LOCATIONS.md) for config truth.
- Prefer [../fastreact-nano/docs/security.md](../fastreact-nano/docs/security.md) for security and policy truth.

## Not Current Documentation

The archive may mention removed adapters, old gateway/Feishu code paths, older version numbers, unsupported startup flows, and obsolete config locations. Those references are historical.

Do not include archived files in maintained documentation inventories except through this index.
